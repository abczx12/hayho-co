# hayho.co Android V1

Một UI dài duy nhất, không tab; floating overlay; nút ⚡; kéo được; tự thích ứng dọc/ngang; landscape compact; có Voice, Effects, Smart Audio, Mixer, Music, Presets UI.

Build bằng điện thoại: upload project lên GitHub → Actions → Build hayho.co APK → Run workflow → Artifacts → tải hayho-co-debug-apk.

Đây là V1 UI/overlay prototype. Slider hiệu ứng chưa phải DSP audio hoàn chỉnh và Android không đảm bảo microphone ảo cho mọi game/app.
